**The Velvet Vault** — a top-down stealth heist game. You are Wren, a thief loose in the Marlow Gallery after closing time. Slip past patrolling guards and their sweeping vision cones, dodge the security cameras, lift the Starlight Opal and the side loot, and reach the getaway door before the alarm meter fills. Three rooms, two tools (tossed coins to pull guards away, smoke pellets to vanish), several routes through every room, and a getaway rating that pays off a clean plan.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, click to toss a coin at a spot, press Q for a smoke pellet, E (or Space) to grab loot, P to pause. No build step, no network requests: every file the game loads lives under `game/`.
